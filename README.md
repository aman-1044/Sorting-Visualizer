
SortVisualizerFX

SortVisualizerFX is a JavaFX-based application that visually demonstrates popular sorting algorithms. It helps users intuitively understand how sorting works through animated visualizations.

Features

- 🎞️ Real-time graphical representation of sorting algorithms
- 🖱️ Simple, interactive interface
- 🧩 Built using JavaFX

 Sorting Algorithms Implemented

- Bubble Sort
- Selection Sort
- Insertion Sort
- (Add more if applicable...)

 Prerequisites

Make sure you have the following installed:

- Java Development Kit (JDK 11 or higher)
- JavaFX SDK
- An IDE like IntelliJ IDEA or Eclipse (recommended), or command-line tools

Installation and Running

 1. Clone the Repository


git clone https://github.com/aman-1044/Sorting-Visualizer.git
cd Sorting-Visualizer


 2. Navigate to the Entry File

The main class for launching the GUI is:

src/main/java/com/aamatucci/sortvisulizerfx/sortVisualizer.java

Open this file in your IDE and run it directly.
